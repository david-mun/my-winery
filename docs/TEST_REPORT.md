## DB·도메인 검증

`tests/database.test.ts`는 PGlite PostgreSQL 엔진에 버전형 migration 네 개를 적용한다. Auth/Storage 시스템 스키마와 역할을 테스트용으로 구성하고 SQL, FK, CHECK, trigger, RLS 및 RPC를 실행한다.

- 서로 다른 사용자, 관리자, 비활성 사용자, 익명 역할의 조회·변경 권한과 owner 불일치 FK 공격을 검사한다. 관리자에게 타인의 와인·후기 조회 권한을 부여하지 않는다.
- 영수증 직접 쓰기를 차단하고 RPC의 합계 검증·실패 rollback·수정 버전 충돌을 검사한다.
- 39,900원 묶음 한 줄과 병별 NULL 가격, 18,000원 할인 한 줄, NV/UNKNOWN 구분을 검증한다.
- 동일 스냅샷 반복 이관 시 중복이 없고 원본 또는 이관 대상이 변경되면 중단하는지 검사한다.
- 마지막 관리자 비활성화·강등·Auth 사용자 삭제, 일반 사용자의 관리자 작업 및 최초 관리자 중복 등록을 거부한다.
- 초대 상태 전이, private Storage 읽기 정책, 직접 업로드 금지를 검사한다.
- 도메인 테스트는 원본 대조, 외부 URL, 파일 signature/재인코딩/EXIF 제거, JSON·multipart 요청 크기 제한을 포함한다.

PGlite는 실제 PostgreSQL 실행 엔진이지만 단일 연결 테스트다. 서로 다른 DB 연결에서 동시에 관리자를 강등하는 경쟁 조건은 이 결과만으로 검증되었다고 주장하지 않는다.
