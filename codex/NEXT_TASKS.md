# 후속 작업용 짧은 프롬프트

## 환경 설정
현재 구현한 코드와 설정 문서를 검사해 Supabase Free 프로젝트 준비, GitHub private repo 구성, Vercel 환경변수 등록을 위한 정확한 작업 체크리스트를 작성해줘. 키·토큰을 채팅이나 Git에 노출하지 말고 실제 외부 변경 전에 내 승인을 받아줘.

## 품질 점검
My Wine List의 인증/RLS/관리자 API/저장소 접근권한을 공격자 관점에서 검토하고, 서로 다른 두 사용자 계정으로 데이터 격리가 동작하는지 자동 테스트를 추가해서 실행해줘.

## 이관 점검
`data/source_manifest.json`의 10종/12병/2건/293,900원 검증 기준을 바탕으로 migration dry-run을 실행하고 세트 금액 중복 및 할인 누락 여부를 검증해줘.

## 모바일 UI 개선
360px, 390px, 768px, 1440px에서 와인 목록·상세·영수증·관리자 화면의 가독성과 터치 조작성을 검토하고 개선해줘.
